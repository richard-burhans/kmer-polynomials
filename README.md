# kmer-polynomials

k-mers as polynomials over the Gaussian integers, with A = 1, C = i, G = −i, T = −1. Under this map complement is
−p(x) and reverse is x^{k−1} p(1/x).

[IDEAS.md](IDEAS.md) lists the ideas to follow (KP-1 to KP-14), each with a check, plus the experiment order,
literature to check and open questions. Private while it is exploratory.
